# Harsh Verma

Online résumé for Harsh Verma, Software Development Engineer 2 at Expedia Group. The page is static HTML and CSS so it can be hosted with GitHub Pages from the repository root, including under the `/MyResume/` project path.

**Live site:** https://harsh3305.github.io/MyResume/

Visible copy follows the current résumé. The phone number is omitted from the public page. [`Harsh-Verma-Resume.pdf`](Harsh-Verma-Resume.pdf) is that résumé for download.

## Local preview

Serve the repository root so asset paths resolve the same way they do on GitHub Pages:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/`. Relative URLs also work when the site is hosted at `/MyResume/`.
